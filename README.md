# 适练有据

老年人居家运动视频说法核查与跟练准备助手。参赛作品：2026 中小学智能未来邀请赛 · 向善智创应用（科学建议方向）。

很多老年人跟着短视频在家锻炼，视频里常有“所有老人都可以照做”“越痛越有效”这类不看个人情况的说法，家里的椅子、地面和是否有人协助也会影响能不能安全跟练。适练有据把这两件事放在一起看：

1. **核查视频里的具体说法**：AI 听取语音、读取字幕、观看画面，逐条列出健康说法和出现时间，再与本地资料库（国家卫健委、中国疾控中心、英国 NHS 公开资料）对照。
2. **检查跟练准备条件**：结合本人已知条件、活动区域照片和实际使用的器材，用本地规则给出具体的最小行动。
3. **生成限定范围报告**：写明查了什么、没查什么，可下载 Markdown 或 JSON。

应用不做诊断，不开运动处方，不给训练量，也不对整段视频或个人打“安全分”。

## 评委快速上手

**不需要 API Key 就能体验完整效果。** 页面内置 3 个示例案例，一键载入视频、场地照片和预先保存的真实模型分析结果；核查说法、规则检查、报告生成都能直接操作。想上传自己的视频，才需要自备 API Key（见后文）。

### 1. 准备环境

- Python 3.11 或更高版本。
- 不需要单独安装 FFmpeg，安装依赖时会自动获得；已安装系统 FFmpeg 的会优先使用。

### 2. 安装并启动

Windows PowerShell：

```powershell
cd 解压后的目录
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python -m streamlit run app.py
```

macOS / Linux：

```bash
cd 解压后的目录
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -m streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`；若端口被占用，加 `--server.port 8600`。

### 3. 一键体验示例案例（无需 API Key）

在页面中间或左侧栏点任一案例，再顺着页面往下看：

| 案例 | 看什么 |
|---|---|
| **B 椅子坐站**（推荐） | 同一段视频，在 ④ 点 B1、B2、B3 三个示例条件：协助缺口、带轮椅子、脚边小物品的提示会随条件变化；B3 会自动换成“调整后”的场地照片 |
| **A 坐姿活动** | ② 里同一段视频的几条说法被分成“与资料冲突”“资料不足”“有限范围有依据”，每条都能展开看资料原文摘录和适用范围 |
| **C 扶椅提踵** | 范围外的疗效说法保留“资料不足”，被反对的说法不会被误判为视频在推荐，器材被遮挡时保留“未知” |

可以尝试的交互：

- 点说法或动作旁的“回看此处”，播放器会跳到对应时间。
- 在 ② 展开“回看与更正识别”，改文字或立场、确认已回看；旧核查结果会失效（重新核查需要 API Key，撤销更正后可点“恢复示例核查结果”）。
- 在 ④ 手动修改任何一项本人条件后提交，规则在本机实时重算。
- 在 ⑤ 生成报告，预览并下载 Markdown 或 JSON。
- 点左侧“退出示例”，回到上传自己文件的模式。

示例中的**视频与场地照片识别结果、说法核查结果**，是此前对 `samples/` 素材真实调用 qwen3.8-omni-flash 后保存下来的原始结果，页面载入时不会再次调用模型；④ 的规则检查和 ⑤ 的报告是在本机实时计算的。示例里的本人条件均为虚构。

### 4. 用自己的视频和照片（需要 API Key）

视频与照片的内容提取、说法核查由大模型完成，需要阿里云百炼（DashScope）的 API Key。**本压缩包不含作者的密钥**，请使用自己的 Key：

1. 登录[阿里云百炼控制台](https://bailian.console.aliyun.com/)，在“API-KEY”页面创建 Key，地域选“华北2（北京）”。新用户通常有免费额度，以官网说明为准。
2. 用文本编辑器打开 `.env`，把第一行改成 `DASHSCOPE_API_KEY=你的Key`，保存后重新启动。其余项保持默认即可。

`.env` 只保存在本机。API Key 必须与服务地址同属一个地域；默认地址为北京。左侧栏的“运行状态”会显示 Key 与 FFmpeg 是否就绪。可选自检（会产生一次很小的模型调用）：`python scripts/check_setup.py`。

在页面 ① 上传一个不超过 120 秒的中文 MP4，点“提取视频内容”，再依次完成 ② 核查、③ 上传 2 到 4 张场地照片、④ 检查准备条件、⑤ 生成报告。

## 它怎样保证结果可靠

- **资料可核对**：8 张资料卡（`knowledge/evidence.json`）逐条记录来源、原文摘录、适用范围和核对日期。界面上的来源名称、链接和摘录由程序从本地读取，模型无法自行编造引用。
- **五种结论，不混为一谈**：有限范围有依据、与资料冲突、超出依据、当前资料不足、需要确认。查不到资料只显示“资料不足”，不等于“错误”。
- **保留原意**：识别到“有人说越痛越有效，这种说法不要照做”时，记录为反对语境，不会误判视频在推荐硬撑。
- **照片只记录看见的**：椅子是否稳固、防滑不能由照片证明，必须由本人确认；没有确认就保持“未知”。
- **模型回复先校验再展示**：结构、引用编号、适用范围任一不符，就降级为“资料不足”或明确显示失败，不会静默当作没问题。

## 隐私

- 视频和场地照片会发送到 `.env` 中配置的模型服务进行分析。
- 本人身体条件、活动限制、器材确认只在本机会话内参与规则判断，**不发送给模型**。
- 无账号、无数据库；上传文件保存在系统临时目录，超过 24 小时自动清理。

## 使用范围

- 仅限中文 MP4，时长不超过 120 秒、文件不超过 100MB；场地照片 2 到 4 张 JPG/PNG，每张不超过 5MB。
- 视频动作限于坐姿上肢活动、椅子坐站转换、扶椅提踵三类；其他动作只标注“超出支持范围”。
- 报告供家属参考，不能替代医生或康复专业人员的意见。

## 常见问题

- **页面提示缺少 DASHSCOPE_API_KEY**：`.env` 没有保存 Key，或没有放在项目根目录。
- **提示 FFmpeg 未找到**：重新执行 `python -m pip install -r requirements.txt`；或自行安装 FFmpeg，并在 `.env` 设置 `FFMPEG_PATH`。
- **模型调用失败或超时**：确认网络可访问阿里云，Key 的地域与服务地址一致；失败原因和请求编号会显示在页面上。
- **端口被占用**：`python -m streamlit run app.py --server.port 8600`。

## 目录

| 路径 | 内容 |
|---|---|
| `app.py` | Streamlit 网页应用 |
| `src/` | 媒体处理、视频与场地提取、说法核查、准备规则、报告生成、示例模式与页面样式 |
| `knowledge/` | 8 张资料卡和 6 组条件规则 |
| `samples/` | 自制模拟视频与场地图、有许可的真人画面样例；`demo_results/` 是示例模式用的已保存模型结果 |
| `tests/` | 离线自动化测试，不调用模型 |
| `scripts/` | 配置自检和资料校验脚本 |

运行测试：`python -m pip install -r requirements-dev.txt` 后执行 `python -m pytest -q`。资料校验：`python scripts/check_knowledge.py`。

## 技术

Python、Streamlit、Qwen-Omni 多模态模型（阿里云百炼，OpenAI 兼容接口）、Pydantic 结构校验、FFmpeg 媒体处理。
